# Polymarket US Trading Skill

An independently maintained Agent Skill and Python CLI for researching Polymarket US event contracts, evaluating fee-adjusted paper trades, and submitting individually approved orders using the official SDK.

## Install in Codex

Ask Codex's skill installer to install `skills/polymarket-us-trading` from this repository. Then invoke `$polymarket-us-trading` in a new Codex turn.

## Run locally

Clone this repository, enter `skills/polymarket-us-trading`, and follow the [operator guide](skills/polymarket-us-trading/README.md).

The public commands work without an account key. Live orders require an eligible account, local credentials, an exchange preview, and your approval of the exact order. Research and paper results do not demonstrate profitability.
